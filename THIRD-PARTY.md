Touch OS (this repository) is distributed under the **MIT** license (see `LICENSE`). None of the components below is
included in the repository, except where noted: the installer downloads them onto the user's computer, each under its own
license. For that reason this project's MIT license does not apply to them.

| Component | Author | License | Where/how |
|---|---|---|---|
| [Tela icon theme](https://github.com/vinceliuice/Tela-icon-theme) (`Tela-<color>*` variants) | Vinceliuice | GPL-3.0 | `install.sh` downloads tag `2026-07-07` from GitHub, verifies its SHA-256 and generates the variant matching the accent color; alternatively it uses a `Tela-<variant>/` folder the user places next to the script |
| [adw-gtk3](https://github.com/lassekongo83/adw-gtk3) | lassekongo83 | LGPL-2.1 | `tools/fetch-adw-gtk3.sh` downloads a pinned version, verified with SHA-256 |

Like its siblings Glassy and Outkast OS, Touch OS needs **no extension from extensions.gnome.org**: the Shell stylesheet is
loaded by the Touch Shell extension itself.

## Credits

- **Palette, wallpapers, shapes, gestures** — original to this project: the palette ("Ink & Iris") and its accents, the
  aurora wallpapers generated by `tools/make-wallpapers.sh`, the touch-sized proportions of the theme and the edge-gesture
  vocabulary.
- **Structure** — the layout of the repository, the installer/uninstaller scaffolding (backup of every setting, manifest,
  dry-run), the headless test bench and the template engine come from the sibling projects **Glassy** and **Outkast OS**
  (MIT, same author), reworked here. No visual design or interface code is shared with them.
- **Behavior it builds on** — GNOME Shell's overview, Dash, on-screen keyboard and `SwipeTracker`, which the extension reuses
  rather than reimplements. Gestures like "pull up from the bottom edge" are common to phones and tablets; no code or
  artwork from any of them is used.

## Notes

- **Tela icons and MIT.** Tela is GPL-3.0: redistributing it inside an MIT repository would not be correct. That is why
  `Tela-*/` is in `.gitignore` and the installer downloads it straight from the author. Touch OS does not modify the icons
  and contains no copy of them. The screenshots in `docs/` show a desktop where the Tela icons are not installed (the
  test bench uses GNOME's own icon set).
- The `extension/touch-shell@touch-os` extension uses GNOME Shell's APIs (GPL-2.0-or-later) through the Shell's modules,
  like every extension; the MIT license is compatible with the GPL.
- Trademarks mentioned (GNOME, Tela, etc.) belong to their respective owners; this is an independent project and is not
  affiliated with them.
